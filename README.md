## 方法论底座：三件工具

讲者在第一讲开头就先声明：**"国际关系不是事实，是看待事实的工具。"** 同一堆事实，换工具就有不同结论。这是理解全部讲次的第一把钥匙。

| 工具 | 核心命题 | 典型用法 |
|---|---|---|
| **现实主义** | 决定国家地位的是工业能力、资源、生产能力，以及**使用这些能力的意图与组织**，与政体无关 | 伊朗"具备超级大国实力"；日本"体量不够却无主权"；阿联酋"库存外包，意愿不在自己手里" |
| **自由主义**（经济学/贸易秩序视角） | 谁在维持秩序、谁在破坏秩序、成本由谁承担 | 伊朗是贸易秩序中的"负面国家"；西方"去工业化"是拆解意识形态压力的策略，而非愚蠢 |
| **马克思主义**（列宁主义视角） | 康德拉季耶夫长波（约 60 年）决定革命窗口；全球化受益方必然生产出自己的掘墓人 | 各讲共用的骨架（见下节） |

讲者自述是**"彻头彻尾的列宁主义者"**，并强调现实主义是常用工具，理由直白：**"越接近康波节点，现实主义就越好用"**——因为此时人们不再看愿景，只看库存。

## 系列骨架：康波阶梯

各讲看似分属不同地区，其实都在回答同一个问题：**1991 年建立的这套秩序，正在怎么散架，散架到哪一步了。**

```
1789 革命 ──1815 维也纳体系
1848 革命 ──1878 柏林会议
1917 革命 ──1945 联合国体系
1968 革命 ──1991 苏联解体 / 华盛顿共识   ← 我们活在这一格
        └── 2028 前后？                  ← 各讲都在描述这一段的裂解
```

**贯穿性的关键推论**：

1. **1968 年是分水岭。** 中国输出"世界各民族一律平等"，苏联输出无产阶级革命，两大意识形态压力迫使西方做了两件事：给少数族裔法律地位 + **把工人阶级"消灭掉"**（去工业化）。这一步不是"西方人傻"，而是被逼出来的拆招。
2. **去工业化的后果**，就是移民一讲的核心：白人无产阶级变成"无用阶级"，成为排外民粹的土壤；同时全球化的成本由地下社会（器官、毒品、人口走私）垫付。
3. **1991 年的胜利是未消化完的胜利。** 苏联解体释放出极廉价劳动力，西方在此基础上金融化到 2008 年顶点；代价是**系统性地否定自己的殖民地历史**，让白人产生负罪感——这是今天"白人身份危机"的思想起点。
4. **2008 年是可修复的，2016 年没有修复。** 伯南克的资产负债表修复方向"全对"，但在 2013→2015 的政治压力下被打断，特朗普上台彻底堵死这条路。
5. **2028 年前后是康波底。** 这一轮的革命窗口已打开（法国街头、美国内战化、日本右转、伊朗内爆）。

## 各讲之间如何呼应

### 一条总纲

中期选举一讲里最锋利的一句，实际上解释了全部讲次：

> "现在是世界秩序在支配美国，而不是美国在支配世界秩序。"

| 讲次 | 表面在讲什么 | 实际在说明"秩序如何支配这个国家" |
|---|---|---|
| 伊朗 | 美伊战争 | 一个具备超级大国实力的国家，恰处在康波革命节点上，战争结果会改写中东国境线 |
| 日本 | 日本右转 | 无主权 + 体量不足 + 秩序震荡 → 只能由"一小撮不理智的激进者"替全社会做选择 |
| 俄乌 | 战争走向 | 真正决定结局的是美国四派、俄国三派、欧盟一派的内部算计 |
| 移民及白人 | 足球与人口 | 全球化把"人"也工业化了；移民问题不是因，是全球化成本的外部化 |
| 中期选举 | 一场选举 | 选举结果不改变美国走向，因为基本面（内战 + 外战合流）已定 |
| 法国 | 街头运动 | 财政危机 → 左右极端化 → 1789/1917 式而非 1848/1968 式的革命 |

### 三组横向接线

**① 伊朗 ↔ 俄乌：2023-10-07 的真正起点**

伊朗一讲提出一个被主流叙事忽略的判断：哈马斯在 2023-10-07 之前访问过莫斯科，真主党与伊朗官员也访问过莫斯科，而那天恰是普京生日。讲者倾向于把这次袭击理解为**俄罗斯在战场承压时开辟第二战场**。俄乌一讲从另一侧补全：普京 2014 年之后做了三手准备，三股势力彼此传递了"乌克兰不堪一击"的错误信息。**两个战场是同一个压力系统的两个出口。**

**② 日本 ↔ 俄乌：同一种"无人负责体制"**

日本：90% 时间极度保守，1% 时间由激进者推动剧变。俄乌：统俄党、大陆军、皇俄三股力量各自为政，"每个人都做好自己的事"，最后没人真正决定。讲者称之为"日本式的决策瘫痪在俄国重演"。

**③ 移民及白人 ↔ 法国：1968 的两个分支**

移民一讲的框架（1968 → 去工业化 → 无用阶级 → 身份危机）在法国一讲收到具体账单：财政危机 → 教育削减 → 中学生上街 → 工会 → 黄马甲 → 极左极右同时起飞。**同一个 1968，在美国表现为 MAGA 与万斯，在法国表现为梅朗雄与勒庞。**

### 共同的"预言坐标"

| 讲次 | 时间判断 |
|---|---|
| 伊朗 | "五年之内可以看到中东国境线的颠覆性冲击" |
| 日本 | "这一天（中日摊牌）必然会发生，且拖的时间不会太长" |
| 俄乌 | "最先出事的应该是美国"；"27 年前后有一种毛骨悚然的感觉" |
| 移民及白人 | "1968 + 60 = 2028，前后就会出现转折" |
| 中期选举 | "中期选举不决定两年后的大选，基本面才决定" |
| 法国 | "这一波更接近 1789 和 1917，而不是 1848 和 1968" |

不同的地区，多次指向同一个窗口：**2027–2028**。

### 共同的结论（讲者本人的收束）

1. **中国是唯一没有下场的大国。** "这场大洗牌中中国一定是最有实力、最有信心活到最后的。"
2. **机遇大于风险，但代价必须说清楚。** "抗日战争对中华民族是利好，但谁也不想再来一次。"
3. **对个人的要求只有一句**：不下牌桌、卡住位置、不犯大错。
4. **方法上：远离碎片化信息，建立体系化的判断框架。**

## 如何阅读

- **第一遍**：按讲次顺序读，因为讲者会在后续讲次里不断回指前面的框架。
- **第二遍**：按主题读。例如"康波"一条线可以串起全部讲次；"白人工人阶级"一条线可以串起移民、法国、中期选举三讲。
- **单讲笔记的统一模板**：讲座定位 / 核心命题 / 论证主线（带时间戳）/ 关键概念与自创术语 / 讲者的判断与预测 / 未展开与留白 / 与其他讲次的接点。

### 两种阅读格式

每份笔记同时提供 **Markdown** 与 **HTML** 两个版本，内容一一对应：

| 用途 | 建议打开 |
|---|---|
| 在线浏览、GitHub 内查看 | `.md`（GitHub 自动渲染） |
| 离线阅读、打印、手机看 | `.html`（单文件、无外部依赖，双击即开） |

HTML 版带有本讲目录、上一讲/下一讲导航与统一排版，并在页脚标注内容立场。若两者不一致，**以 `.md` 为源文件**（HTML 由 Markdown 生成）。

`appendix/transcripts/` 保留原始转写（仅做标点与分段处理），用于核对笔记中的时间戳与引述；它不是逐字稿校对版，`[NNNm]` 为块起始时间标记。
