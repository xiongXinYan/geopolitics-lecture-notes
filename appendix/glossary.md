# 附录一 · 术语表与自创概念索引

> 本表按字母/主题混排，标注首次出现的讲次，方便交叉检索。

## A. 讲者的核心分析工具

| 术语 | 讲者定义 | 首次出现 |
|---|---|---|
| **现实主义** | 决定国家地位的是工业能力、资源、生产能力，以及**使用这些能力的意图与组织**；与政体无关 | 伊朗 |
| **自由主义（工具）** | 从贸易秩序与经济学角度看谁在维持秩序、谁在破坏秩序、成本由谁承担 | 伊朗 |
| **马克思主义（工具）** | 以约 60 年康波为骨架，看革命窗口与"全球化受益者生产出自己的掘墓人" | 伊朗 |
| **康波（康德拉季耶夫周期）** | 约 60 年一轮的长波；讲者给出的四轮节点：1789 / 1848 / 1917 / 1968 → **2028** | 伊朗 |
| **今天死 / 明天死** | 弱势行为体在国际结构中的两难选择：没有最优解，只有"今天死"和"明天死"两个选项 | 伊朗 |
| **摘果子** | 革命后由组织化集团收割宪政成果（教士集团两次摘取） | 伊朗 |
| **扁平军队** | 巴列维把军队拆成互不统属、各师团单独效忠国王的结构 | 伊朗 |

## B. 伊朗相关

| 术语 | 说明 |
|---|---|
| **教士集团 / 乌里玛** | 伊朗特有阶层：权力由教团内部自我授予（不依赖君主的科举），本身是大地主、有武装 |
| **凯加（恺加）王朝** | 波斯最后一个封建王朝，突厥军人入主，类比"波斯版晚清" |
| **礼萨汗 / 巴列维** | 前者是"成功的袁世凯"，后者是被推翻的末代国王 |
| **教法学家治国（velayat-e faqih）** | 霍梅尼的建国思想；最高领袖由 88 人专家委员会选出 |
| **大红海战争** | 讲者对萨赫勒—红海代理人战争的命名（埃塞俄比亚/埃及以南，部落与军阀战争，死亡上百万人） |
| **海合会（GCC）** | 讲者判断其正在瓦解——军事上证明无力自保 |

## C. 日本相关

| 术语 | 说明 |
|---|---|
| **霸府国家** | 讲者用中国史概念翻译"幕府国家"：权力在大将军，皇帝仅象征 |
| **小确幸文化（原词为日语）** | 极度尊重日常与职业、在乎自己的小世界、主动制造信息茧房——日本文化核心 |
| **万世一系的神国** | 元朝时期日本发明的自我定位理论 |
| **日本版中华正统论** | 明亡后德川时期完成：你们已亡国，我们才是中华 |
| **金融战败** | 日本央行行长著作概念：日本不是"跌下第一"，是被**冻结** |
| **1993 年激进改革** | 众议院选举改革，拆掉派阀、官僚、财阀三大抓手 |
| **"一小撮不理智的激进者"** | 日本每次剧变的实际推手：大化改新、明治维新、昭和军部、高市早苗 |

## D. 俄乌相关

| 术语 | 说明 |
|---|---|
| **统俄党 / 大陆军 / 皇俄 / 俄共** | 俄国四股力量；后两者才真正掌握基层 |
| **黄俄 / 皇俄** | 支持沙皇复辟的组织，背后是沙皇格勒基金会（白俄贵族后代回流） |
| **斯拉夫异教派** | 以"小阿姨"（克里米亚检察长）为代表的极右翼，用异教符号替代东正教 |
| **英雄时代计划** | 战功换公务员/土地的军功体制 |
| **苏罗维金防线** | 2022 年秋之后的俄军防线，标志战争转入一战式对峙 |
| **帕兰提尔（Palantir）** | 硅谷右翼介入乌克兰的技术与政治载体 |
| **格雷厄姆之死** | 讲者视为"美国建制派对战争管理的终结"标志 |
| **冻结 = 二流国家** | "只有二流国家才能被冻结"——所以在此之前战争不会冻结 |

## E. 移民及白人相关

| 术语 | 说明 |
|---|---|
| **无用阶级 / 废人阶级** | 去工业化后既无工作、又靠福利存活的白人群体 |
| **1968 总开关** | 中国输出"各民族一律平等" + 苏联输出阶级革命 → 西方两次拆招（给少数族裔法律地位 + 消灭自己的工人阶级） |
| **白左** | 接受"祖先有罪"叙事的自由派白人 |
| **抽象老哥** | 讲者对欧美极端行为的调侃式概括 |
| **地下社会** | 全球化未覆盖地区形成的器官/毒品/人口走私跨国网络 |
| **布雷维克事件** | 2011 年挪威于特岛，82 人；讲者视为"白人对全球化的系统性清算" |
| **米莱 / 万斯** | 两个案例：一个"改革内容对、时机全错"，一个"被民主党生产出来的反全球化者" |

## G. 法国相关

| 术语 | 说明 |
|---|---|
| **高卢雄鸡** | 法国民族认同的政治建构：不是罗马人、不是法兰克人，而是古老高贵的高卢人后代 |
| **周天子式集权** | 派监察官（太上皇）而非消灭大贵族 |
| **用虚荣换忠诚** | 路易十四的集权模式（"我即国家"），只有他本人能玩转 |
| **法国版秦始皇** | 讲者对拿破仑的评价：省—县制、民法典、中央行政 |
| **高利贷帝国主义** | 资本外投、靠利息生存（列宁术语），"20% 的结算纯靠利息" |
| **分票策略** | 萨科齐分右翼、奥朗德分左翼、马克龙统中间 |
| **1789 模式 / 1848 模式** | 1789 = 战争时期 + 内战；1848 = 和平时期 + 街头 |
| **秘密结社传统** | 法国右派能长期站住脚的社会学基础 |
