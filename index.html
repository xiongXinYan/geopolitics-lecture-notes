方法论底座 · 三件工具

TOOL 01

现实主义

决定国家地位的不是政体，而是工业能力、资源、生产能力，以及使用这些能力的意图与组织。

伊朗"具备超级大国实力" · 日本"体量不足却无主权" · 阿联酋"库存外包，意愿不在自己手里"
TOOL 02

自由主义

谁在维持秩序、谁在破坏秩序、成本由谁垫付。讲者用它推翻了一个流行叙事：西方去工业化不是"傻"，是被 1968 年的意识形态压力逼出来的拆招。

伊朗是贸易秩序的"负面国家" · 全球化的成本由地下社会垫付
TOOL 03

马克思主义

约 60 年一轮的康波，决定革命窗口。核心命题：全球化受益方，必然在自己的内部生产出掘墓人。

"越接近康波节点，现实主义就越好用"——因为此时人们不再看愿景，只看库存

接线图 · 各讲如何彼此呼应

伊朗 ↔ 俄乌

2023-10-07 不是起点，是第二次开辟的战场。哈马斯与真主党在袭击前都去过莫斯科，而那天恰好是普京生日。伊朗战场与乌克兰战场，是同一套压力系统的两个出口。

日本 ↔ 俄乌

"无人负责体制"的两次验证。日本：90% 时间保守 + 1% 时间由激进者推动。俄国：统俄党、大陆军、皇俄各做各的，最后把国家带进一个没人真正决定的结局。

移民 ↔ 法国

同一个 1968，两张账单。在美国表现为 MAGA 与万斯，在法国表现为梅朗雄与勒庞——都是"去工业化 → 无用阶级 → 财政危机 → 街头"的同一条链。

中期选举 → 法国

中期选举一讲的结尾只留了一句话："这不是偶然，这是康波已经开始了，法国已经点上了。"下一讲用 123 分钟把这句兑现。

伊朗 ↔ 中期选举

伊朗战争是中期选举的第一号议题标签——它同时打击共和党的爱国选民、福音派、摇摆州的中东移民，是特朗普最大的政治包袱。

全部讲次 → 同一句总纲

"现在是世界秩序在支配美国，而不是美国在支配世界秩序。"这一句出现在中期选举一讲，但它实际上是全系列共同的方法论前提。

全系列的共同结论

  1. 中国是唯一没有下场的大国。"这场大洗牌中，中国一定是最有实力、最有信心活到最后的。"
  2. 机遇大于风险，但代价必须说清楚。"抗日战争对中华民族是利好，但谁也不想再来一次。"
  3. 对个人的要求只有一句：不下牌桌、卡住位置、不犯大错。
  4. 方法上：远离碎片化信息，建立体系化判断。这也是整个系列的方法论承诺——"坚定信心，开拓视野"。
